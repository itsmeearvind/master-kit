# master-kit
Master Kit - Production-ready, secure &amp; scalable Full Stack boilerplate. Auth (Google, GitHub, Facebook, Email, Mobile OTP) + RBAC + WhatsApp Cloud API + Razorpay (Card, UPI, Bank Payout) + Themeable Admin Dashboard + Notifications + Audit Logs + Search/Filter/Sort. Client's DB, not ours.. Built with Turborepo, Fastify, Prisma, Redis.
